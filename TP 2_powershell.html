Descripción de la Actividad

Ejercicio 1

1) Escribir un programa en Power Shell que pregunte el nombre del usuario en la consola y después que el usuario lo introduzca, muestre por pantalla la cadena ¡Hola <nombre>!, donde <nombre> es el nombre que el usuario haya introducido. 

# Solicitar el nombre al usuario
$nombre = Read-Host "Introduce tu nombre"

# Mostrar el saludo por pantalla
Write-Host "¡Hola $nombre!"

Ejercicio 2

2) Escribir un programa que pregunte al usuario por el número de horas trabajadas y el coste por hora. Después debe mostrar por pantalla la paga que le corresponde. 

# Horas trabajadas y costo por hora
[float]$horas = Read-Host "Introduce el número de horas trabajadas"
[float]$coste = Read-Host "Introduce el coste por hora"

# Calcular la paga correspondiente
$paga = $horas * $coste

# Mostrar el resultado por pantalla
Write-Host "La paga que te corresponde es: $paga"

Comandos Principales Utilizados

  • Read-Host: Solicita datos al usuario por consola en tiempo de ejecución.
  • Write-Host: Muestra texto estático o el valor de variables por pantalla.
  • Variables ($nombre, $horas, $coste, $paga): Almacenan los valores ingresados y calculados utilizando el símbolo $.
  • [float]: Convierte el valor ingresado a número decimal para poder multiplicar horas por coste.
