PARTE 01 • EJERCICIO 1 ejercicio1.ps1

1) Escribir un programa en Power Shell que pregunte el nombre del usuario en la consola y después que el usuario lo introduzca, muestre por pantalla la cadena ¡Hola <nombre>!, donde <nombre> es el nombre que el usuario haya introducido.

Código Fuente PowerShell 
# Solicitar el nombre al usuario
$nombre = Read-Host "Introduce tu nombre"

# Mostrar el saludo por pantalla
Write-Host "¡Hola $nombre!"
Al ingresar Cristian Edgardo Paz cuando Read-Host lo solicita, la variable $nombre se interpola dentro de las comillas dobles en Write-Host.

PARTE 02 • EJERCICIO 2 ejercicio2.ps1

2) Escribir un programa que pregunte al usuario por el número de horas trabajadas y el coste por hora. Después debe mostrar por pantalla la paga que le corresponde.

Código Fuente PowerShell 
# Horas trabajadas y costo por hora
[float]$horas = Read-Host "Introduce el número de horas trabajadas"
[float]$coste = Read-Host "Introduce el coste por hora"

# Calcular la paga correspondiente
$paga = $horas * $coste

# Mostrar el resultado por pantalla
Write-Host "La paga que te corresponde es: $paga"
El tipado explícito [float] convierte la entrada de texto de Read-Host en un valor numérico decimal antes de multiplicar $horas * $coste.

GLOSARIO TÉCNICO DE POWERSHELL

COMANDOS UTILIZADOS

Read-Host Entrada de Consola

Solicita datos de entrada al usuario en tiempo de ejecución desde la consola y los almacena por defecto como cadena de texto (string).

Write-Host Salida por Pantalla

Muestra resultados, cadenas de texto estáticas y valores de variables por pantalla en la consola de PowerShell.

Variables ($nombre, $horas, $coste, $paga) Almacenamiento

En PowerShell se declaran anteponiendo el signo $ al identificador y se asignan mediante el operador =.

Conversión de tipo [float] Tipado Explícito

Declara explícitamente variables numéricas de punto flotante (decimales) para poder realizar operaciones aritméticas de multiplicación ($horas * $coste).
